# Titanic Survival Analysis

This notebook explores the Titanic dataset to understand passenger survival using data cleaning, exploration, and visualization techniques.

## Project Overview

This project includes:
- **Data Cleaning**: Handling missing values in `Age`, `Embarked`, and `Cabin`
- **Exploratory Data Analysis (EDA)**: Generating summary statistics
- **Visualization**: Using Seaborn and Matplotlib to explore:
  - Survival distribution
  - Gender and class survival rates
  - Age and fare distributions
  - Correlation heatmap

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
